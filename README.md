This repository contains a collection of my Java-based web development projects. These projects were created to practice and demonstrate skills in Java, JSP, Servlets, MySQL, and web application development.

## Project List

### 1. Employee Leave Management System
- A web application to manage employee leave requests and approvals.
- Admin can approve or reject leave requests.
- Employees can apply for leaves and view their status.
- Built using Java, JSP, Servlets, and MySQL.

### 2. Library Management System
- Helps manage library books and members.
- Admin can issue or return books, and manage book inventory.
- Includes member login and book search functionality.
- Built using Java, JSP, Servlets, and MySQL.

### 3. Online Feedback System
- Allows users to submit feedback online.
- Admin can view feedback responses and analyze them.
- Simple interface for both users and admins.
- Built using Java, JSP, Servlets, and MySQL.
