# Employee Leave Management System

This project is a web-based application designed to manage employee leave requests and approvals. It provides separate interfaces for administrators and employees, facilitating efficient leave management within an organization.

## Features

- **Admin Panel**:
  - Add, update, and delete employee records.
  - View and manage leave requests.
  - Approve or reject leave applications.

- **Employee Panel**:
  - Apply for leave.
  - View leave status and history.
  - Edit personal details.

## Technologies Used

- **Backend**: Java, JSP, Servlets
- **Frontend**: HTML, CSS
- **Database**: MySQL
- **Server**: Apache Tomcat
